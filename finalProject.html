The web changes when people ask it to. Now it’s our turn.

Every big shift in web design started as a grassroots push. Designers made CSS Zen Garden. Developers fought for web standards. Builders got HTML5 semantics. The next move is making information available to everyone, on every device, for every body and brain.

Every upgrade started with people

None of these arrived because browsers felt generous. People organized, built examples, and kept asking.

  1. 1998

    Web standards

    The code shift. The Web Standards Project pushed browsers to follow the same rules, so developers could stop building a different site for each browser.

  2. 2003

    CSS Zen Garden

    The design shift. One HTML page, hundreds of looks. It proved that style could live in CSS and that CSS could be art.

  3. 2014

    HTML5 semantics

    The content shift. Elements like header, nav, main and article gave pages meaning that software can read, not just pixels people can see.

  4. Now

    Universal design

    The access shift. Build it so the most people can use it, in the most situations, without a special version. This one is ours to start.
