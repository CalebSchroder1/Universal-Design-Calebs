Meta: this site has to follow its own advice

A site about universal design that isn’t universally designed would be a bad joke. Here’s how this one is built and how it was checked.

Mobile first, then responsive

The styles in styles.css were written for a narrow phone screen first (about 320 pixels). Wider layouts are added with min-width media queries written in em, so they follow the visitor’s font size. Grids use repeat(auto-fit, minmax(…)) so cards wrap by themselves, and flexbox handles the navigation and button rows.

There’s no horizontal scrolling at 320 pixels except inside code blocks and tables, which scroll within their own box and can be reached with the keyboard.

The look

The style is a sticker-pack look: chunky ink outlines, hard offset shadows, and flat color. It’s playful, but the structure stays calm so the content comes first.

  • Body type: Atkinson Hyperlegible, a typeface designed by the Braille Institute so letters are easy to tell apart.
  • Headings: Bricolage Grotesque, a friendly, slightly quirky grotesque.
  • Code: the system’s monospace font.
  • Color: an ink-blue text color, one violet accent, and a yellow marker, plus three soft tints.

Built-in accessibility features

  • A skip link is the first thing you reach with the keyboard.
  • Landmarks (header, nav, main, footer), one h1 per page, and headings in order.
  • The current page is marked with aria-current="page" and with a fill and underline, not just color.
  • A thick focus ring on every control, and the nav, buttons, and settings are at least 44 pixels tall.
  • There is no JavaScript at all. Every feature is plain HTML and CSS.
  • The building blocks on the How page and the myths on the Why page use native details and summary. They open with Enter or Space and need no ARIA.
  • The site follows your device’s light or dark setting and its increased-contrast setting, so people don’t have to hunt for a theme switch.
  • Motion is off when you ask for reduced motion, and forced-colors mode keeps borders and focus visible.
  • Zoom is never disabled, and all text is sized in rem.
